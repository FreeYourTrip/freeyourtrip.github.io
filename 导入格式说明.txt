旅行心愿地图 — 导入格式说明
================================

同一输入框会自动识别两种格式。推荐使用管道格式，改起来最直观。
在「示例行程」页点击「导入行程」，把文本粘贴进去即可。
格式错误时会用中文指出第几行（或 JSON 第几条）出了什么问题；正确的行仍会导入。


一、管道格式（推荐）
--------------------

固定 5 列，用半角 | 或全角 ｜ 分隔：

  类型 | 名称 | 地址 | 日期时间 | 备注

空单元格也要保留竖线，这样列才对得齐。不必写表头；如果第一行正是
「类型 | 名称 | 地址 | 日期时间 | 备注」，导入时会自动跳过。

类型：
  机票
  酒店
  地点
  地点可以带亚类，例如：地点/餐厅、地点/景点、地点/街道

机票：
  名称 = 航班号
  地址 = 出发和到达的 IATA 三字码，例如 LHR - HND
  日期时间 = 出发当地墙钟时间 ~ 到达当地墙钟时间
            例如 2026-12-01 09:30 ~ 2026-12-02 07:00
            （各写各机场的当地时间，不要先换算成浏览器时区）
  备注 = 自由文本。若写有「座位 32A」「确认号 ABC123」，会单独抽出。

酒店：
  名称 = 酒店名
  地址 = 地址（也可以是地图链接）
  日期时间 = 入住日期 ~ 退房日期，例如 2026-12-04 ~ 2026-12-07
  备注 = 自由文本。若写有「确认号 ABC123」，会单独抽出。

地点：
  名称 = 地点名
  地址 = 文字地址，或地图链接（若链接里带有经纬度，会用来在地图上打点）
  日期时间 = 可选，YYYY-MM-DD 或 YYYY-MM-DD HH:mm
  备注 = 自由文本

示例（可直接复制到导入框）：

类型 | 名称 | 地址 | 日期时间 | 备注
地点 | 大英博物馆 | Great Russell St, London WC1B 3DG | 2026-12-05 10:00 | 免费，建议预约
酒店 | The Savoy | Strand, London WC2R 0EZ | 2026-12-04 ~ 2026-12-07 | 确认号 ABC123
机票 | BA123 | LHR - HND | 2026-12-01 09:30 ~ 2026-12-02 07:00 | 座位 32A

导入后会用 OpenStreetMap Nominatim 把文字地址/名称编成坐标（无需 API Key，
每秒最多 1 次请求，结果缓存在本机）。机票优先查内置的主要机场表（含 LHR、
HND、PVG 等），找不到再搜索「<IATA> airport」。
若没有结果或多个候选，预览里会用黄色标出，可挑选或改词重试；整批仍可导入。


二、JSON
--------

以 [ 或 { 开头的内容会按 JSON 解析。同一框里也可以同时粘贴管道行和 JSON，会一并导入。

约定的英文字段（推荐机器导出用）：

  机票  { "type": "flight", "flight_no": "BA123", "from": "LHR", "to": "HND",
          "depart": "2026-12-01 09:30", "arrive": "2026-12-02 07:00",
          "confirmation": "可选", "seat": "可选" }

  酒店  { "type": "hotel", "name": "The Savoy", "address": "Strand, London WC2R 0EU",
          "check_in": "2026-12-04", "check_out": "2026-12-07", "confirmation": "可选" }

  地点  { "type": "place", "subtype": "餐厅", "name": "Dishoom Covent Garden",
          "address": "12 Upper St Martin's Ln, London WC2H 9FB",
          "map_url": "可选的地图链接", "date": "2026-12-05", "note": "可选" }

也仍支持中文键：类型、名称、地址、日期时间、备注。

Dishoom 示例（可直接复制）：

[
  {
    "type": "place",
    "name": "Dishoom Covent Garden",
    "address": "12 Upper St Martin's Ln, London WC2H 9FB",
    "date": "2026-12-05",
    "note": "印度早餐，建议早去排队"
  }
]


三、导入之后
------------

- 条目会按日期时间排到时间线上（航班按出发地当地日期，到达按目的地当地日期）。
- 相邻且都有坐标的条目之间会出现「起点名 —— 终点名」连接条。
- 导入的行程会保存在本机浏览器（localStorage），刷新后还在。
- 也可以勾选「追加到当前行程」。若当前是自带示例，会复制一份再追加，以免改掉示例。
